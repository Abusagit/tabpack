# Maps-routing active-only activations: full training and epoch 3

Active-only activations are connected through a benchmark-only bridge. `ActivationTransfer` packs the native first-block output directly into active ID order and unpacks before the native output head. Fixed parameter and optimizer-state slots remain, and the same grouped fixed-slot optimizer is used. `ActiveFixedSlotMLP` supports zero hidden depths so models that only have a native first block pass through. Forward/backward GEMMs and optimizer GEMMs use 64x64 tiles; active blocks are unfused.

Same preprocessed TabReD Maps-routing split, 64 sampled diverse candidates, seed 0, widths [64,128,256,384,512], batch size 1024, BF16 autocast, independent per-model shuffles, early-stopping and greedy ensemble. Both runs sequential on RTX A4000 device 1; sampled hyperparameters and first-three-epoch shuffle hashes match. The active-only run trains until normal stop, while the fixed-column control was stopped at 3 epochs; first 12 batches of epoch 3 are profiled in both. Two prior complete train/validation epochs precede the capture. All 64 candidates are still active at epoch 3.

Phase times are sums of attributed GPU kernel durations per batch. Step is median synchronized wall time from forward through zero_grad, with profiler on, excluding data gathering. A profiler checkpoint is saved before capture; reset of peak stats occurs immediately after capture starts. Peak GPU memory includes resident train and validation data and training objects. Both are single 12-batch profiler captures and do not demonstrate a significant speedup. They should not be directly compared to previous train-only epoch-3 profiles whose validation and full training state were not resident.

Active-only full run: 89 epochs, 479.23 s total `train` wall, 477.94 s training-loop time, overall train peak allocated 2.8775 GiB and reserved 3.1992 GiB, validation RMSE 0.161089 and test RMSE 0.161099. Profiling and checkpoint overhead are included in the full wall time; final validation/test predictions and data loading are excluded. The earlier full fixed-column run took 313.96 s over 61 epochs, on a different GPU and without profiling; stopping history, device and profiling differ, so the difference does not isolate per-step speed. The active-only backend reported 19,224 calls, zero fallback calls and 78 transfer rebuilds. All 64 candidates were active at the epoch-3 measurement, so the measured peak does not demonstrate expected savings after candidates stop.

Eleven correctness tests passed, including native comparison, dropout, gradients, different depths, reordering and model removal/checkpoint sync.
